# 🚚 Product Delivery App (Сервис доставки продуктов)

**Лабораторная работа №3 (Вариант 17)**  
*Сложность: Well-done*

## 📖 Описание проекта
Приложение представляет собой MVP-систему для управления доставкой продуктов.
Проект реализован на языке **Python** с применением объектно-ориентированной парадигмы (ООП).

Система включает в себя:
- **Веб-версию** (FastAPI) — для работы через браузер.
- **Десктопную версию** (PySide6) — в виде нативного приложения с современным интерфейсом.
- **Единую базу данных** (PostgreSQL в Docker), к которой одновременно подключаются оба интерфейса.
- **Автоматические тесты** (pytest) для проверки бизнес-логики.

### 🛠 Стек технологий:
- **Backend:** Python 3.11, FastAPI, SQLModel (SQLAlchemy + Pydantic)
- **Frontend (Web):** Jinja2, HTML5, CSS3, JavaScript (Chart.js)
- **GUI (Desktop):** PySide6 (Qt), Matplotlib
- **База данных:** PostgreSQL 16 (в Docker)
- **Инфраструктура:** Docker, Docker Compose
- **Тестирование:** Pytest

## 🚀 Инструкция по запуску

### Предварительные требования:
- Установленный **Python 3.11+**
- Установленный **Docker Desktop** (должен быть запущен)

### Шаг 1. Клонирование репозитория и установка зависимостей
git clone https://github.com/verrronikaat/product_delivery_app.git
cd product_delivery_app
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install "psycopg[binary]"

### Шаг 2. Запуск базы данных и веб-версии (Docker)

docker compose up -d --build
Веб-версия будет доступна по адресу: http://localhost:8000

Документация API (Swagger): http://localhost:8000/docs

### Шаг 3. Запуск десктопного приложения
Убедитесь, что база данных из Шага 2 запущена, и в новом терминале (с активированным .venv) выполните:

python desktop_app.py
### Шаг 4. Запуск тестов (Pytest)

pytest tests/ -v
Тесты используют SQLite в памяти, поэтому Docker для них не обязателен.

## 📚 Краткая справка (Руководство пользователя)
📦 Вкладка «Товары»
Позволяет добавлять новые товары на склад.

Необходимо указать название, цену, количество и выбрать категорию.

В таблице отображаются текущие остатки. Если товара меньше 5 штук — цифра подсвечивается красным.

👥 Вкладка «Клиенты»
Здесь создаются карточки клиентов (ФИО, телефон, адрес), а также добавляются новые категории товаров.

🛒 Вкладка «Заказы»
Позволяет оформить заказ. Вы выбираете клиента из выпадающего списка, товар и количество.
При оформлении заказа система автоматически списывает товар со склада и сохраняет заказ в историю.

📊 Вкладка «Статистика»
Содержит два графика:

Динамика заказов — показывает количество оформленных заказов за последние 7 дней.

Топ товаров — показывает самые популярные товары по количеству проданных единиц.

📝 Вкладка «Лог активности»
Фиксирует все действия пользователя: добавление товаров, клиентов, оформление заказов, а также ошибки ввода.

🌐 Веб-версия
Веб-интерфейс полностью дублирует функционал десктопа. Вы можете добавить товар на сайте, а затем нажать «Обновить» в десктопном приложении — и увидите его там (так как база данных общая).
